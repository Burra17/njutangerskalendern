# Njutångerskalendern

Vad händer i Njutånger? En enkel kalender över fikor, loppisar, möten, städdagar och annat i byn, byggd för mobilen.

Händelserna läggs in i en publik Google Kalender, och sajten läser dem via Google Calendar API. Ingen egen server och ingen databas.

Arbetet sker i [projektet](https://github.com/users/Burra17/projects/7) med en ticket per PR. Se [CLAUDE.md](CLAUDE.md) för arbetssättet och [docs/projektspecifikation.md](docs/projektspecifikation.md) för originalspecen.
